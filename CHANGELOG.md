# История версий

Здесь записано, что было сделано в каждой версии лабораторной работы.
Каждой версии в git соответствует метка (тег) с тем же именем.
Новые версии добавляются сверху.

## v0.1 — 2026-10-06

Выполнена часть 1 из 3: многофайловый проект на основе лабораторной работы №3 и статическая
библиотека. Лабораторная работа разделена на три логические части: статическая библиотека (v0.1),
динамическая библиотека (v0.2), сравнение и итог (v1.0).

### Сделано

- Класс `Polynomial` из ЛР №3 перенесён в `include/Polynomial.h` и `src/Polynomial.cpp` без изменений
  кода; в комментариях заголовка убраны ссылки на страницы ЛР №3.
- Клиентский код `client/client.cpp` — один файл для обеих тестовых программ: значения, корни,
  операции, сравнения, статические счётчики библиотеки и исключения, брошенные библиотекой и пойманные
  клиентом; 23 проверки, итог и код возврата.
- `build_static.bat` — ручная сборка прямыми вызовами `g++` и `ar` (без make и CMake): `Polynomial.o`,
  статическая библиотека `liblab3.a`, `client.o`, `test_static.exe`.
- Схема сборки `uml/Build.puml` (картинка `uml/Build.png`), страница документации `pages/part1.md`,
  README.

### Проверено

- Сборка `g++ -std=c++14 -Wall -Wextra -pedantic` (g++ 16.2.0) — без ошибок и предупреждений.
- `test_static.exe` — 23 проверки из 23, код возврата 0.
- Клиент замечает ошибки библиотеки: в испорченной копии `valueAt` проваливаются 2 проверки из 23,
  код возврата 1.
- `ar t build\liblab3.a` — в библиотеке один объектный файл `Polynomial.o`; `objdump -p` — у
  `test_static.exe` нет собственной `lab3`-библиотеки среди зависимостей, только системные DLL Windows.
- Doxygen 1.18.0 собирает документацию без предупреждений; схема — PlantUML 1.2026.8.
