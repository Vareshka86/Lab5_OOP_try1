# Лабораторная работа №5 по ООП

Статическая и динамическая библиотеки на C++14 — консольная программа по лабораторной работе №5.

Проект выполняет [лабораторную работу №5](https://aleksandr-003.github.io/labs/OOP_z/Labs1_5.html) курса «Объектно-ориентированное программирование и проектирование» (А. Д. Смородинов): класс из лабораторной работы №3 собирается в статическую и динамическую библиотеки и подключается к одному и тому же клиентскому коду. Работа сдаётся по частям: каждая часть выходит отдельной версией.
